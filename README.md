# Sentence-embedding-and-cosine-similarity-for-verse-recommendation
Try : https://sentence-embedding-and-cosine-similarity-for-recommendation.streamlit.app/
A personality assessment tool taking free text input to 8 deeply self-reflective questions and using NLP that classifies users into Karma, Bhakti, or Jnana Yoga tendencies and recommends relevant verses ; also displays a radar chart showing inclination towards each category.
Many people are interested in applying the wisdom of the Bhagavad Gita to their daily lives, but it can be difficult to know which teachings resonate with them personally.
Traditional personality quizzes or recommendation systems do not incorporate philosophical/spiritual texts effectively.
Build a personality assessment tool using NLP that classifies users into Karma, Bhakti, or Jnana Yoga tendencies and recommends relevant verses with explanations.
Tools : sentence embedding, cosine similarity, text preprocessing
